O problema

Museus comunitários têm acervo e programação ricos, mas o site costuma ficar parado: cada mudança depende de alguém que saiba programar.

Como funciona

  1. Site com identidadeOs 5 elementos, espaços, linha do tempo com fotos, programação e como visitar.
  2. Painel ADM com PINA equipe entra com PIN e edita textos, programação, visita, redes e fotos.
  3. Edições salvasUm servidor Cloudflare guarda as mudanças e o site mostra na hora.
  4. DivulgaçãoQR code no estilo visual do site, para cartaz, ingresso e chaveiro.
